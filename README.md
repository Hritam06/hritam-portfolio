## Featured projects

The projects below are independent cybersecurity tools developed and maintained in their own repositories. Their source code, detailed documentation, release history, and technical limitations are documented separately.

### SOC Sentinel

**Python-Based Security Monitoring & Threat Detection**

A Python-based security monitoring and investigation toolkit that ingests, validates, and normalises security events; detects suspicious authentication, network, and DNS activity; correlates related events; and generates structured investigation reports with heuristic risk assessments and MITRE ATT&CK mappings.

**Areas covered**
- Security event ingestion, validation, and normalisation.
- Authentication, network, and DNS threat-detection heuristics.
- Cross-event correlation, structured alerts, and risk assessment.
- MITRE ATT&CK mappings and JSON/HTML investigation reporting.

[View SOC Sentinel repository](https://github.com/Hritam06/soc-sentinel) · [V2.0.0 release](https://github.com/Hritam06/soc-sentinel/releases/tag/v2.0.0)

### KASEVRA

**Digital Forensics & Evidence Integrity Toolkit**

An offline-first Python digital evidence toolkit supporting file-level evidence acquisition, SHA-256 integrity verification, baseline comparison, Ed25519 digital signatures, and hash-linked chain-of-custody records, with structured JSON and HTML reporting.

**Areas covered**
- File-level evidence acquisition and SHA-256 manifest generation.
- Independent integrity verification and baseline comparison.
- Ed25519 digital signatures and hash-linked chain-of-custody records.
- Structured JSON and HTML reporting.

[View KASEVRA repository](https://github.com/Hritam06/kasevra) · [V2.0.0 release](https://github.com/Hritam06/kasevra/releases/tag/v2.0.0)

> **Project scope:** These are independent projects. SOC Sentinel produces heuristic investigative signals that require analyst validation. KASEVRA supports file-level evidence integrity workflows; its hashes, signatures, and custody records do not independently establish evidence authenticity, provenance, completeness, or legal admissibility. Refer to each project's documentation for its full scope and limitations.

## Run locally

The portfolio is a static website and does not require a package installation or build process.

Clone the repository:

```bash
git clone https://github.com/Hritam06/hritam-portfolio.git
cd hritam-portfolio
```

Start a local static server from the repository root:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. You can also open `index.html` directly, although using a local server more closely reflects normal website serving.
